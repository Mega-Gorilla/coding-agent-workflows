# Startup Status

Treat GitHub Issues as the primary source of planned work when the repository follows an Issue-first workflow.

1. Inspect open Issues and pull requests, including the current user's status views when useful.
2. Check recent commits and workflow runs.
3. Read related documentation or search repository conventions only when needed to interpret the current state.
4. Summarize the current state, in-flight work, completed work, and blockers in Japanese.

This is a read-only status workflow. Do not create files, modify the repository, or post comments unless the user separately requests it.
